# Credit Risk Portfolio Analytics & Default Prediction

## Project Overview

This project analyzes LendingClub consumer loan data to identify factors associated with loan default and develop a model for estimating default risk.

The project combines portfolio analytics, SQL, Python, machine learning, model explainability, and an interactive dashboard to examine credit risk from both a technical and business perspective.

## Business Problem

Lenders need to understand which borrower and loan characteristics are associated with higher default risk while maintaining a healthy and profitable loan portfolio.

This project seeks to answer:

> **Which borrowers and loan characteristics create the greatest default risk, and how can the portfolio be managed more effectively?**

The analysis is designed from the perspective of credit risk managers, underwriting teams, and business leaders.

## Project Objectives

- Analyze the composition and risk characteristics of the loan portfolio.
- Identify borrower and loan characteristics associated with default.
- Develop a model to estimate the probability of loan default.
- Create interpretable borrower risk segments.
- Evaluate portfolio risk using financial and credit-risk metrics.
- Build an interactive dashboard for communicating portfolio and model results.
- Develop practical recommendations based on the analysis.

## Data

The project uses historical LendingClub accepted-loan data covering 2007–2018.

The raw dataset is not stored in this GitHub repository due to its size. Dataset documentation and a data dictionary are maintained in the `docs/` directory.

## Tools & Technologies

- **Python:** Data cleaning, exploratory analysis, feature engineering, machine learning, model evaluation, and explainability
- **SQL:** Portfolio-level and segment-level credit risk analysis
- **Pandas & NumPy:** Data manipulation and numerical analysis
- **Matplotlib & Seaborn:** Data visualization
- **scikit-learn:** Predictive modeling and model evaluation
- **SHAP:** Model explainability
- **Jupyter:** Analytical notebooks
- **Tableau / Power BI:** Interactive portfolio dashboard
